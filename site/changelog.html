[v0.32.0] — 2026-08-15

Security

  • CNI plugin lookup rejects plugin types that are not one normal path component.
  • Colima commit/save archive import canonicalizes config and layer entries and rejects extraction-root escapes.

Changed

  • Handler function coverage is enforced at an 80% threshold; measured coverage is 92.41% (207/224 functions).
  • The main CI pipeline runs cargo xtask verify; stability gates also run on pushes to develop.
  • The mandatory stability checklist was consolidated to six gates, all passing.
  • SmolVM command execution was deduplicated into a shared implementation.

Fixed

  • Restored the missing macbox VZ trait import and fixed the clippy issues it exposed.
  • Corrected the stability doc-sync path to the canonical feature matrix.
  • Fixed the benchmark registry fixture so image config blobs are served and cached.

Removed

  • Deleted an orphaned duplicate crates/minibox/src/domain.rs; canonical domain ports live in minibox-domain.

[v0.31.0] — 2026-05-26

Added

  • minibox-mcp, a policy-gated MCP stdio server for doctor, container/image listing, logs, manifests, pull, run, stop, and remove workflows.
  • SmolVM local OCI tarball loading into the VM image cache.
  • Expanded benchmark/regression tooling, showcase workflows, generated CLI schema, testing documentation, and SOPS-backed maintainer backup workflows.

Changed

  • User and platform documentation was aligned with current adapters, commands, capabilities, and limitations.
  • CLI daemon-error and missing/unexpected-response diagnostics became more explicit.

Fixed

  • mbx diagnose includes recent logs; pause/resume terminal handling and mbx ps polling parsing are more reliable.
  • Paused-state restart persistence, SmolVM async execution and local-image tagging, and multiple CI quality gates were corrected.
  • cargo xtask doctor became the canonical tool/environment preflight.
  • Image pulls return typed manifest/layer size errors; GKE path diagnostics use display formatting.

Earlier Releases

v0.24.0 — 2026-05-07: first public release, adding the reusable conformance suite, Crux JSON-RPC plugin, smolvm default with krun fallback, restart support, and daemon hardening.

v0.23.0 — 2026-04-28: workspace consolidation, typed adapter selection, restart reconciliation, macOS adapter wiring, and GKE image push.

v0.2.0 — 2026-04-14: exec, logs, events, networking, mounts, image management, pause/resume, and observability foundations.

v0.1.0 — 2026-03-17: initial daemon/CLI runtime with OCI pulls, namespaces, cgroups v2, overlay filesystems, and lifecycle operations.
