Ownership Boundaries

minibox-domain

Owns domain ports and values. The paths minibox_core::domain and minibox::domain re-export the same type identities for compatibility.

minibox-core

Owns DaemonRequest/DaemonResponse in protocol.rs, Unix-socket client transport, image storage, registries, layer extraction, garbage collection, leases, and Dockerfile parsing.

minibox

Owns native container primitives, shared adapters, daemon server/state, and the split request-handler modules under daemon/handler/.

miniboxd

Builds native, GKE, Colima, smolvm, and krun handler dependencies. VZ uses a separate feature-gated startup path because Virtualization.framework boot must use the macOS main queue.

User and Agent Control Surfaces

  • mbx: button-primary CLI, including optional read-only tui.
  • minibox-mcp: policy-gated MCP tools over stdio.
  • minibox-crux-plugin: JSON-RPC stdio operations for Crux workflows.

Canonical xtask Shape

Use grouped commands such as cargo xtask test unit, cargo xtask test property, cargo xtask test conformance, and cargo xtask check protocol-drift. The old hyphenated test aliases are not button-primary guidance.
