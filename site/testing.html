Test Helpers

minibox::testing, behind test-utils, provides handler-oriented mocks, fixtures, helpers, and backend capability descriptors. The daemon handler tests target modules under crates/minibox/src/daemon/handler/.

minibox-core::adapters, also behind test-utils, provides canonical cross-platform doubles, fixtures, and conformance support. Domain trait identities originate in minibox-domain.
